# 포트폴리오에 사용할 소개

## 조건 변화에 따른 AI 음성 탐지 모델의 취약점 분석

게임에서 상대의 평상시 행동만으로는 봇을 구별하기 어렵지만 특정 상황에서 차이가 드러난다는 관찰에서 출발했다. 이를 음성 탐지에 적용해 같은 음성을 원본·느린 배속·빠른 배속으로 비교하는 실험을 설계했다.

“합성 음성의 호흡과 강약 변화가 부자연스러워 보인다”는 가설을 시간적 반복 지표로 탐색했다. 속도를 유지한 1.0배 재처리 대조를 포함하고, 배속에 따라 달라지는 검사 구간 수를 기록해 처리 과정의 영향을 함께 살폈다.

공개 음성 원본 64개에서 파생한 256개 입력을 고정된 사전 학습 모델로 평가했다. 세 조건의 점수 평균에서 EER이 21.875%에서 15.625%로 낮아졌지만, 고정 판정 기준에서 사람 오탐은 28/32에서 32/32로 늘었다. 이 결과를 실사용 성능 개선으로 채택하지 않고 검증 범위와 한계를 기록했다.

원시 점수·실험 조건·입력 및 모델 해시를 보존하고, GPU 없이 지표를 다시 계산할 수 있는 검증 도구와 자동 테스트를 구성했다. 가설 제안은 사용자가 담당했고 코드 구현·실험 실행·검산·문서화에는 Codex의 지원을 사용했다. 기반 신경망은 원 제작자의 모델을 활용했다.

### 연결할 증빙

- 저장소 README: 질문·구조·결과·한계.
- evidence/frozen/results.csv: 파일별 결과.
- evidence/frozen/protocol.json: 결과 관찰 전 고정한 조건.
- GitHub Actions 실행 링크: 해당 커밋에서 지표 재검산과 변환 검사가 통과한 기록.

### 주장하지 않는 것

새 대형 모델 직접 학습, 호흡 탐지기 개발 완료, 모든 생성기에 공통된 특징 발견, 실시간 사기 통화 판별, 독립 자료에서의 확정된 성능 개선.
