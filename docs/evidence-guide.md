# 주장과 증빙

| 주장 | 확인 방법 | 증빙의 한계 |
|---|---|---|
| 같은 원본을 네 조건으로 비교했다 | protocol / prep_manifest / results의 ID·조건·해시 대조 | 원본 64개의 화자·대본 독립성 미확인 |
| 저장된 EER·AUC 수치를 재계산할 수 있다 | `voice-shift-probe audit --evidence evidence` | 원음·GPU 추론을 다시 실행하는 검증은 아님 |
| 1.0배 재처리 영향도 고려했다 | 결과 표 및 파일별 점수 변화 | 대조의 변화만으로 정확한 원인까지 규명하지 못함 |
| 음높이를 유지하며 배속을 바꾼다 | FFmpeg 통합 테스트의 440Hz 신호 | 합성 신호 검사는 실제 모든 음성의 품질을 보증하지 않음 |
| 반복 지표가 반복 신호를 측정한다 | 반복 신호와 무작위 신호 비교 테스트 | AI만의 반복이나 호흡 사건을 검증하지 않음 |
| 지표 개선과 오탐 악화를 구분했다 | 원본 EER 0.21875 / 평균 0.15625; 사람 오탐 28 / 32 | 관찰한 작은 자료에서의 결과 |

## 기록의 출처

- 실험 수행: 2026-09-29, 무료 Colab Tesla T4.
- 공개 정리: 2026-10-02. 과거 기록을 고쳐 실험 날짜를 새로 만들지 않았음.
- frozen/ 파일은 원래 실험의 선택된 기록을 그대로 복사함.
- source_locators.json은 원래 입력 출처 기록에서 공개 데이터 위치와 해시만 추려 생성함.
- index.json은 내보낸 파일의 해시 목록. 자체 작성 기록이며 제삼자 인증서가 아님.
- 원본 음원, 모델 가중치, 계정 화면, 개인 경로는 공개 묶음에 넣지 않음. frozen 코드의 work/outputs 상대 경로는 당시 프로젝트 구조를 나타냄.

## 자동 검증의 의미

GitHub Actions는 CPU에서 지표를 재계산하고 입력 검증·배속 대조·알려진 반복 신호를 검사합니다. 성공 표시가 있다면 해당 커밋에서 이 검사가 통과했다는 증빙으로 사용할 수 있습니다. 성공 표시가 원래 GPU 실험 실행, 실제 통화 탐지 성능 또는 독립 자료의 성능 개선을 인증하지는 않습니다.

원래 전체 원음 검산 기록은 additional_gpu_analysis.json에 보존했습니다. 이 저장소의 CPU audit는 원음을 포함하지 않아 그 파일의 과거 원음 검사를 새로 수행하지 않습니다. 새로운 모델 추론·원음 재현에는 별도 데이터·외부 모델·GPU 환경이 필요합니다.
